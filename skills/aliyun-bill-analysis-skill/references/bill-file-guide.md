# 客户账单导出要求

请从阿里云费用与成本控制台导出“消费明细”或“计费项明细”账单，优先选择新版 V2 格式。

交付前确认：

1. 文件覆盖需要分析的全部月份；
2. 导出的是明细账单，不是只有产品合计的月账单；
3. 不要手工删除、合并或改名表头；
4. 多个月份可以分别导出，也可以放入同一个目录或 ZIP；
5. 当月账单尚未结束，只能作为阶段性数据；
6. 不要把 PDF 月账单作为计费项分析输入。

支持：

- `.xlsx`；
- UTF-8、UTF-8 BOM、GB18030 `.csv`；
- 包含 XLSX/CSV 的 `.zip`；
- 多文件目录。

不支持：

- 加密 ZIP；
- 宏工作簿；
- PDF；
- 缺少计费项字段的普通汇总表。
