# Obsidian 笔记规范

## 路径和命名

仓库根目录：`E:\Obsidian Vault\Book`

路径：`主要学科\主要主题\《中文书名》— 作者.md`

- 使用中文正式书名；没有通行中文名时使用原文名。
- 副标题、原文名和其他译名不放入文件名。
- 多位作者使用顿号；作者过多时可用“第一作者 等”。
- 替换 Windows 文件名非法字符 `< > : " / \ | ? *`，同时在 YAML 保留准确书名。
- 一本书只保存一份；不同版本只有内容差异显著且用户需要分别研究时才拆分。
