# 跨书观点比较

## 触发条件

仅在以下情况执行：

- 仓库中有相同主要主题的书；
- 多本书明确回答同一核心问题；
- 新书与已有笔记存在重要的支持、修正或反对关系；
- 用户明确要求比较；
- 同类书推荐恰好已存在于仓库。

仅共享宽泛学科但研究问题不同，不足以触发比较。

## 定向检索

从新书提取主要学科、主要主题、核心问题和 3 至 7 个核心概念。先搜索 YAML，再搜索正文。按相关性最多读取 3 至 5 本已有笔记，不加载整个仓库。

## 比较单位

围绕具体问题比较，不写泛泛的“这两本书都很值得读”。分析：

- 共同问题；
- 各自结论；
- 概念定义；
- 基本假设；
- 使用的证据；
- 分析层级；
- 适用场景；
- 实践建议；
- 能否相互兼容；
- 综合判断。

分歧可能来自定义、对象、分析层级、证据、时代背景、因果解释或价值目标。先解释分歧来源，再判断是否真正冲突。

## 写入格式

```markdown
## 与库内已有书籍的观点关联

### 与《书名》— 作者的关系

- 共同问题：
- 一致观点：
- 主要差异：
- 差异来源：
- 证据与适用场景：
- 实践上的互补或冲突：
- 综合判断：
```

没有实质关联时省略本节，不保留空标题。

## 更新保护

默认只在新笔记中记录关联，不自动修改旧笔记。若反向关联有明显价值，在预览中列出建议更新的旧文件和内容；只有用户确认后才修改。

## 同类及延伸书籍

默认推荐 3 至 6 本，但不凑数。关系可为入门、深入、补充、对照、反方、更新或应用。

每本说明：

```markdown
### 《书名》— 作者

- 推荐关系：
- 共同问题：
- 主要差异：
- 为什么值得一起读：
- 建议阅读顺序：
- 适合读者：
```

推荐依据应是问题、理论、证据或实践关系，而不是销量、榜单或营销书单共现。
