# 临时 AK/SK 使用要求

当客户不方便导出文件或需要补齐账期时，使用账单 API 入口。

1. 由客户创建本次项目使用的临时 RAM 用户；
2. 只授予费用中心账单读取所需的只读权限；
3. 客户可以直接将 AK/SK 发给售后，售后一次性粘贴到当前对话；
4. 执行过程只显示 AccessKey ID 末四位，不复述完整凭据；
5. 不把 AK/SK 写入配置、报告、中间文件或普通日志；
6. 成功或失败后，都提醒客户禁用并删除本次 AK。

不要推荐主账号 AK，也不要授予`AliyunBSSFullAccess`。

Skill 只能提醒凭据回收，不能声称已经替客户删除凭据。
