# 报表口径

## 1. 金额

消费金额统一使用`应付信息/应付金额（含税）`，逐行转换为 Decimal 后再汇总。零金额和负金额均保留。

## 2. 计费方式

- `PayAsYouGo`：后付费；
- `Subscription`：包年包月；
- `Other`：未知类型、退款、调账或其他尚未确认的费用。

只使用费用类型映射，不使用交易类型推断计费方式。

## 3. 账单分析

分组键：

```text
计费方式 × 产品Code × 账单月份
```

名称只用于展示。同一个产品Code出现多个名称时，展示出现次数最多的非空名称，并在数据说明中记录冲突。

## 4. 后付费分析

只统计标准计费方式为`PayAsYouGo`的记录。

启用地域维度时，分组键：

```text
产品Code × 计费项Code × 地域Code × 地域名称 × 用量单位 × 账单月份
```

关闭地域维度时：

```text
产品Code × 计费项Code × 用量单位 × 账单月份
```

用量为空时不按零处理。用量只能在计费项和单位一致时相加。

## 5. 趋势

趋势表展示完整月份数据，图表默认只展示费用最高的前10个产品或计费项。当前未结束月份必须标记为部分月份。

趋势只能说明账单金额或计费用量变化，不能证明资源利用率、闲置、扩缩容或业务原因。

## 6. 对账

必须满足：

```text
标准记录应付金额
= 月份汇总
= 计费方式汇总
= 产品汇总
= 账单分析总计
```

以及：

```text
后付费标准记录应付金额
= 后付费计费项汇总
= 后付费分析总计
= 后付费趋势金额
```
