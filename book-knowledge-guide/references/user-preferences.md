# 用户内容偏好

## 核心价值取向

- 优先客观、准确地还原作者原意和写作问题。
- 深度来自概念、前提、证据、论证、边界和现实验证，不来自堆砌篇幅。
- 判断保持客观、克制、中庸；中庸指结论强度与证据匹配，不是强行折中。
- 不为了区分来源而机械填充外部观点，也不为了批判而批判。
- 重视现实价值，避免没有场景、条件和风险说明的纸上谈兵。
- 用户个人阅读观点由用户在 Obsidian 的“个人备注”中填写，Skill 不代写、不修改。

## 默认分析优先级

以下数字仅表示注意力优先级，不是评分公式：

| 维度 | 优先级 |
|---|---:|
| 作者原意与写作问题 | 5 |
| 核心概念与论证结构 | 5 |
| 现实应用与边界 | 5 |
| 证据质量 | 4 |
| 出版后验证 | 4 |
| 时代与学科背景 | 3 |
| 可靠外部解读 | 3 |
| 同类及延伸书籍 | 3 |

默认聚焦 3 至 7 个核心观点。次要章节可以简要概括；关键概念、核心论证和现实边界应深入展开。不设置固定字数，篇幅服从资料质量和内容需要。

## 学科侧重

### 哲学

重点分析概念定义、隐含前提、论证有效性、思想传统、反例和规范判断。不要强行为纯理论观点生成行动清单。

### 心理学与认知科学

重点分析实验设计、样本、效应、可重复性、后续研究，以及从实验环境迁移到现实场景的边界。

### 经济学

重点分析模型假设、数据与因果关系、制度条件、微观与宏观层级差异，以及政策应用的副作用。

### 管理学

重点分析案例代表性、组织环境、实施成本、失败案例，以及方法是否依赖特定企业、领导者或时代。

### 社会学与政治学

重点分析历史制度背景、分析层级、因果识别、价值前提、跨文化适用性和政策后果。

### 历史与历史理论

重点分析材料来源、叙事选择、因果解释、时代语境和竞争性解释。避免把历史类比直接当作预测。

### 自然科学、医学与健康

重点分析研究共识、证据等级、研究条件、后续更新和安全边界。涉及健康行动建议时优先当前专业指南。

### 计算机科学与人工智能

重点分析技术机制、假设、限制、工程可行性、出版后的技术变化，以及哪些判断已经过时。

### 研究方法与跨学科

重点分析方法适用对象、测量与推断限制、跨领域迁移条件，以及不同学科概念是否被正确对应。

## 偏好更新

只有用户明确表达长期偏好时才修改本文件。不要从一本特殊书籍或一次临时要求推断全局偏好。
