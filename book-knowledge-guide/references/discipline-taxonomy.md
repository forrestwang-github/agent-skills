# 学科与主题分类

## 一级学科

默认使用以下稳定名称：

- 哲学
- 心理学与认知科学
- 经济学
- 社会学
- 政治学
- 历史
- 管理学
- 教育学
- 语言学
- 数学与统计
- 物理学
- 化学
- 生物学
- 医学与健康
- 计算机科学
- 工程与技术
- 研究方法
- 跨学科

能识别主要学科时不要使用“跨学科”兜底。“个人成长”不是一级学科；应判断其知识来源属于心理学、教育学、管理学或其他学科。

## 二级主题原则

- 使用稳定的名词或学科常用概念。
- 主题应足以容纳多本书；细粒度概念先放入 YAML `topics`。
- 创建前检查已有目录和近义名称，优先复用合适的上位主题。
- 预计只涉及一两本书的概念不立即创建目录；同类书达到约 3 至 5 本时再考虑升级。
- 不创建“值得读的书”“提升认知”“热门书籍”等非知识主题。

## 路径选择

选择能够最好解释本书核心问题和主要方法的学科与主题，而不是出版社营销分类。若有多个合理路径：

1. 选择全书论证占比最高的学科；
2. 其次选择作者主要使用的方法所属学科；
3. 再考虑用户最可能检索该书的问题；
4. 将其他关系写入 `related_disciplines` 和 `topics`。

## 主题变更

不得因一本新书随意重命名已有主题。合并、重命名或移动主题前，列出受影响的文件和 YAML 变化并取得用户确认。
