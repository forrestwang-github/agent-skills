# 来源、证据与出版后验证

## 来源优先级

按任务选择最接近原始事实的来源：

1. 原书正文、正式电子版或用户提供的合法文本
2. 原书目录、前言、后记、出版社试读
3. 作者论文、演讲、课程、访谈与后续回应
4. 学术论文、系统综述、元分析、学术书评
5. 大学课程、专业机构、行业指南和权威媒体长篇评论
6. 长期专注该领域、引用规范、论证完整且具有研究或实践背景的内容创作者
7. 普通媒体摘要、读者评论、平台帖子

第 7 类只能作为检索线索，不能独立支撑重要结论。出版社介绍可确认基本定位，但宣传性表述不能直接当作客观评价。

## 外部解读的准入条件

外部解读必须同时满足“来源可靠”和“具有增量”。增量包括：

- 补充时代、学科或思想背景；
- 澄清易误读概念；
- 提供独立证据或后续研究；
- 提供可核验的实践结果；
- 指出明确边界、反例或修正；
- 连接重要的相关理论。

评估内容创作者时，查看其领域积累、引用准确性、推理透明度、研究或实践背景、是否讨论失败与边界以及过往可靠性。粉丝数、点赞量、资历标签或营销包装不构成可靠性证据。

不采用无出处金句、只给结论的高赞短评、把个人体验推广为规律的内容、无法追溯的思维导图、宣传文案复述或明显转述其他摘要的材料。

## 观点归属

重要内容应能辨认属于以下哪类：

- 作者明确主张；
- 根据作者完整论证作出的归纳；
- 外部来源的补充、支持、修正或反对；
- Skill 的综合判断与应用建议。

不要用二手解读单独证明作者原意。无法确认时使用“根据目前可获得的资料”“可以初步概括为”等限定语。

## 证据评估

区分实验、观察数据、历史材料、个案、商业案例、个人经历、思想实验、类比和轶事。分析：

- 证据是否独立于作者结论；
- 样本和场景是否具有代表性；
- 相关性是否被误写成因果性；
- 个案是否被不当推广；
- 测量与定义是否一致；
- 结论强度是否超过证据；
- 是否存在合理的替代解释。

## 出版后验证

### 根据主张类型选择强度

经验性、因果性、预测性、健康、技术、管理和政策主张需要强验证。历史与社会综合框架需要中等验证。纯概念、规范伦理和思想实验以论证与后续批评为主，不能机械套用实验复现标准。

### 优先检索

1. 系统综述和元分析；
2. 独立复现研究；
3. 专业指南或机构共识；
4. 作者后续修正或回应；
5. 长期实践结果和有记录的失败；
6. 高质量领域专家评论。

关注出版时主张、重要后续研究、实践采用或失败以及当前学界或行业位置。没有必要罗列完整时间线，只保留影响判断的节点。

### 分开判断

- 学术验证：后续研究是否支持；
- 复现验证：关键实验或结果能否重复；
- 实践验证：现实环境中是否产生效果；
- 制度验证：是否进入教育、行业或政策体系；
- 时间验证：核心问题和框架是否仍被使用。

持续流行、被广泛引用或进入课程不等同于实证成立。

### 结论措辞

根据证据选用精确表述，例如：

- 后续证据总体支持；
- 得到部分支持，但适用范围缩小；
- 核心框架仍有效，具体机制受到修正；
- 研究结果存在明显分歧；
- 缺少足够的独立验证；
- 主要结果未能稳定复现；
- 在当前技术或社会环境下已经过时；
- 主要具有历史价值。

不能因存在批评就写成“已被推翻”，也不能因长期流行就写成“已被证明”。

## 引用与完整性

笔记正文避免堆满链接，但重要的外部事实、争议、后续验证和直接归因必须可追溯。在“资料依据与完整性说明”中按原始资料和外部解读分组列出标题、作者或机构、年份与链接，并简述使用位置。

不要复制长篇受版权保护的原文。以概括为主；必须直接引用时保持短小、准确并附来源。
